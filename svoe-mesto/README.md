# Своё место — сайт салона красоты

Учебный проект на React + Vite, Node.js + Express и SQLite.

## Что есть на сайте
- Главная страница и информация о салоне.
- Карточки услуг с ценами и длительностью.
- Список мастеров.
- Форма онлайн-записи.
- Сохранение заявок в локальную базу SQLite.
- Локальные SVG-иллюстрации в `client/src/assets`.

## Что нужно установить
1. Установить Node.js версии LTS: https://nodejs.org/
2. Распаковать архив.
3. Открыть папку `svoe-mesto` в Visual Studio Code.
4. Открыть терминал VS Code и выполнить:

```bash
npm run install:all
npm run dev
```

5. Открыть в браузере адрес, который покажет Vite (обычно http://localhost:5173).

Сайт и API запускаются одновременно. База данных создаётся автоматически в `server/database/svoe_mesto.db`.

## Структура проекта

```text
svoe-mesto/
├── client/                 # React-приложение
│   ├── src/
│   │   ├── assets/         # Картинки сайта (SVG)
│   │   ├── App.jsx         # Основные блоки и логика интерфейса
│   │   ├── main.jsx        # Точка входа React
│   │   └── style.css       # Стили
│   ├── index.html
│   └── vite.config.js
├── server/                 # Сервер и база данных
│   ├── database/
│   ├── server.js
│   └── package.json
└── package.json
```

## Важно
Это демонстрационный учебный проект. Перед реальным использованием нужно добавить авторизацию администратора, проверку расписания, защиту персональных данных и HTTPS.
